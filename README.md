TAFEL-PIONTELLI 2.0
Corrosion rate prediction for carbon steel in acidic media

Politecnico di Milano  -  PoliLaPP
M. C. Ben Ameur  |  A. Brenna  |  M. Ormellese

It is free.  There is nothing to buy, nothing to activate.


HOW TO START IT
---------------
Double-click        Tafel-Piontelli 2.0

That is all.  There is no installation, and nothing else to open.  The
whole program is inside that one file.

Want it on the desktop?  Right-click Tafel-Piontelli 2.0, choose
"Show more options" then "Send to > Desktop (create shortcut)".


IF WINDOWS ASKS SOMETHING THE FIRST TIME
----------------------------------------
"Windows protected your PC" appears for any program that has not been
paid to be signed.  Click "More info", then "Run anyway".  It is asked
once, never again.


IF IT ASKS FOR PYTHON
---------------------
The program needs Python on the computer, once.  Press OK when it
offers, or go to

    https://www.python.org/downloads/

and on the first page of the installer tick "Add python.exe to PATH".
Then double-click Tafel-Piontelli 2.0 again.

The first start may show a small window saying one more thing is needed
- the library that draws the charts.  Press "Install now", wait about a
minute, and the program opens by itself.


WHERE YOUR WORK IS KEPT
-----------------------
Projects are saved as .tp2 files wherever you choose.  The program's own
small files - your experimental data, the list of recent projects - are
written next to the program, or in your user folder if this one is
read-only.
